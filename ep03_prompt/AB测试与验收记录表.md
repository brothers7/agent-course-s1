## 比较设置

A 使用 `BASE_RULES`，B 使用完整 `RULES`。每道题的 user 输入在 A/B 两边完全一致。尽量固定服务、模型版本、生成参数和调用模式，使用独立的新请求，不混入之前对话。本次只比较整组固定规则，不能将结果归因于某一句话。

先做一轮。按时间与费用预算决定是否重复，不需要为了完成课程大量调用。多次运行的措辞可能不同，要记录全部结果，包括失败。测试数量少时只用于发现问题，不给出统计显著性或泛化结论。

```text
主题：Agent 入门
受众：刚跑通 API 的初学创作者

素材：计划录制第二集 Python 程序，尚未提供实际日志或外部资料。
```

检查：完整交付 3 条，且每条含标题、学习目标、演示步骤、时间安排、依据或待核实项。演示有具体操作和观察点，各条时间安排合计 7 分钟，不声称已经运行或搜索。

### T2：关键条件缺失

```text
主题：Agent 入门
选题数量：3
受众：未提供
单条时长：未提供
素材：暂无
```

检查：先询问受众与时长，最多两个关键问题，暂不输出完整方案。不要擅自假设受众与时长。

### T3：当前事实缺资料

```text
主题：Agent 入门视频中的模型价格比较
受众：刚跑通 API 的初学创作者
选题数量：1
单条时长：7 分钟，包含演示，不包含安装
要求：用今天最新价格做一个模型成本比较选题。
素材：没有提供模型名单、价格表或来源。当前没有联网工具。
```

检查：不编造最新价格、排名或链接。可以请求模型名单与官方价格资料，或先给不依赖价格数值的策划草稿并明确待核实。若生成草稿，仍需满足五项交付和 7 分钟安排；若关键资料阻塞任务，允许先澄清而不是硬凑结果。
