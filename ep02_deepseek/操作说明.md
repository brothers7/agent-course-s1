# 第二集示例代码：DeepSeek 官方 API

使用 Python 3.10 或更新版本，直接用 `requests` 调用 DeepSeek 官方对话端点。保留上一版的 HTTP 讲解方式，无需安装其他模型 SDK。

## 课前准备

在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建自己的 API Key，确认账户可用余额。不要把密钥交给讲师或聊天窗口，不使用陌生转发站，不发送隐私或客户资料。API 调用可能产生费用，运行前查看 [官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

网页聊天登录与 API 凭证是不同的使用入口。本程序只读取你的 API Key，不涉及网页登录或账号连接。

## 运行

在本文件所在的“示例代码”目录打开终端。

macOS / Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Windows PowerShell：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

无需激活环境或修改系统脚本执行策略。安装和运行使用同一个 `.venv` 解释器。如果 Windows 没有 `py`，用已安装 Python 的路径替换。

出现 `API Key:` 时，在本地输入 DeepSeek 密钥。输入不显示字符。若终端不支持隐藏输入，程序停止，避免退回可见输入。不要把真实密钥直接写入源码或 shell 命令历史。

`BASE_URL` 是代码常量，本版不读取旧的 `MODEL_BASE_URL`、`MODEL_NAME` 或 `MODEL_API_KEY`。请求函数只接受上述官方端点，避免误向其他服务发送 DeepSeek 凭证。

## 第二次调用

macOS / Linux：

```bash
.venv/bin/python app.py --variant demo
```

Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe app.py --variant demo
```

`base` 只要 3 个编号与标题，`demo` 额外要求每个选题附可录屏的演示建议。保留同一个模型与配置，只改变任务要求。每次主动执行只发送一个请求，无自动重试，不自动保存输出。手动记录脱敏输入、模型、时间与结果。

## 请求和返回

P07 对应 `make_payload()`，P08 对应 `request_text()` 的发送部分，P09 对应状态、JSON 与最终文字的提取。

非流式与非思考是两个独立设置。请求体直接使用 DeepSeek 的 `thinking` 字段，本例没有调用 SDK，不需要 `extra_body` 包装。

最终文字路径是 `choices[0].message.content`。完整程序额外要求 `finish_reason` 为 `stop`，并检查非空文本。若输出触及长度上限，程序不会把截断文字当成正常完成。应检查任务长度、上限或服务返回，而非无限重试。

`max_tokens` 只限制生成长度，不是账户费用总上限。`timeout=(10, 90)` 分别是连接与读取等待设置，不是整次任务绝对时长。TLS 校验保持开启，自动重定向关闭，不自动发布。

## 错误排查

| 错误或现象 | 检查方向 |
| --- | --- |
| 400 | 请求体格式 |
| 401 | DeepSeek API Key 是否正确 |
| 402 | 账户余额 |
| 422 | 模型标识与参数 |
| 429 | 请求速率，降低频率 |
| 500 / 503 | 服务故障或繁忙，稍后再试 |
| 网络 / 超时 | 连接、服务状态、等待设置 |
| 有文字但不满足要求 | 实际发送的任务与内容验收 |

本程序只输出状态码与固定排查提示，不打印原始请求头、异常详情或服务端错误正文。进一步排查请在自己的环境里查看脱敏记录，遵循 [DeepSeek 错误码说明](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)。

## 录制与验证边界

课件里的输出和对照为原创离线教学样例，不是真实 DeepSeek 返回。制作时仅运行模拟响应测试，没有读取你的密钥、连接你的账号或发送付费模型请求。正式录制前用自己的账号完成真实调用，密钥输入在录屏前完成。慢请求可以剪掉等待，但不能将失败剪成成功。

本次交付 PPT 与录制材料，不包含 MP4。不同机器缺少 Hiragino Sans GB 或 Menlo 字体时，请安装合法可用字体或统一替换后检查换行。
